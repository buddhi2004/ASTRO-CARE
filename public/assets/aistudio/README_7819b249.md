## 🌟 Key Highlights & System Architecture

### 1. Navigation & Dual-Mode Mission Flow
* **Top Navigation Bar**:
  * **`Home`**: Main Dual-Mode operations workspace with instant access to Mode A (In-Flight Co-Pilot) & Mode B (Earth Rehab).
  * **`Architecture`**: Deep technical breakdown of zero-cloud local JSON inference, Butterfly ultrasound protocols, and biomechanical handover equations.
  * **`Deployment`**: Space mission licensing and implementation tiers (Open Challenge, Lunar Gateway, Mars Deep Space Enterprise).
  * **`Impact` (Human Resilience & Earth Impact)**: Demonstrates how offline autonomous crew healthcare addresses deep-space communication latency (up to 20 minutes to Mars) while creating a blueprint for decentralized, offline healthcare in remote clinics, disaster zones, and underserved communities on Earth.
  * **`About`**: Complete profiles and engineering roles for **Udamgie**, **Rashmi**, **Buddhiprabha**, and **Vidasni**.
  * **`Contact`**: Mission Control uplink terminal.
* **Initial Onboarding Gate**:
  * Prominently prompts: **"What is your current mission status?"**
  * **Option A: "Currently On Mission"** &rarr; Generates and displays the **Autonomous In-Flight Countermeasure & Medical Plan**.
  * **Option B: "Already Landed on Earth"** &rarr; Generates and displays the **Personalized 45-Day Earth Reconditioning & Rehabilitation Plan**.

### 2. Mode A: In-Flight Medical Co-Pilot
* **100% Offline Local JSON Rule-Engine (`rules/in-flight-triage.json`)**: Zero network dependency. Evaluates physiological parameters locally with zero latency.
* **Environment Selector**:
  * **Microgravity (ISS / Deep Space - 0.0g)**: Severe cephalad fluid shift (1.45x) and rapid daily muscle deconditioning.
  * **Partial Gravity (Lunar South Pole - 0.16g)**: Partial ground reaction force.
  * **Partial Gravity (Mars Habitat - 0.38g)**: Surface gravity adaptation.
  * **EVA Suit / Rover**: Critical solar energetic particle and radiation flare monitoring.
* **Interactive "Digital Twin" Body Map**: Clickable SVG human figure color-coded (**Green / Amber / Red**) for 4 critical astronaut health domains:
  1. **Cardiovascular / IJV (Internal Jugular Vein)**: Evaluates Doppler flow velocity and cephalad venous stasis to prevent spaceflight jugular vein thrombosis.
  2. **Ocular / SANS (Spaceflight-Associated Neuro-ocular Syndrome)**: Analyzes Optic Nerve Sheath Diameter (ONSD), Frisen papilledema grading, and hyperopic visual shifts.
  3. **Musculoskeletal**: Compares ARED resistance workload, missed workout penalties, and axial spine-lengthening pain.
  4. **Mood & Circadian Sleep**: Tracks actigraphy sleep duration, PVT reaction speed, and habitat ambient $CO_2$ partial pressure.
* **Self-Exam & Triage Drawer**: Step-by-step ultrasound probe placement guides that instruct non-physician astronauts how to position the probe (e.g. cervical triangle for IJV, transbulbar window for ONSD) with instant automated triage actions.
* **NASA Open API DONKI Space Weather Integration (`api.nasa.gov`)**: Pulls live Coronal Mass Ejection (CME) and Solar Flare (FLR) radiation alerts via free `DEMO_KEY` or user keys, backed by an offline cached simulation so the app never fails.
* **In-Flight Daily Prediction Logger**: Records daily metrics to `localStorage` (`astral_med_flight_logs`), establishing an unbroken handover bridge for Mode B after landing.

---

### 3. Mode B: Post-Flight AI Physio & Reconditioning Coach
* **Automated Mission Handover**: Directly imports the astronaut's in-flight logs from Mode A (or supports presets: **30-Day Artemis Gateway, 180-Day ISS, 365-Day Mars Transit**) to calculate:
  * **Predicted Muscle Atrophy %** (targeting soleus & erector spinae)
  * **Bone Density Loss % (BMD)** (targeting femoral neck & calcaneus)
  * **Orthostatic Intolerance / POTS Risk Score (0-100)**
  * **Neurovestibular Ataxia Score (0-100)**
* **Vulnerability Recovery Body Map**: Highlights deconditioned deep spinal stabilizers (multifidus), postural anti-gravity calves, and cervical extensors in Amber/Red.
* **Phased 45-Day Reconditioning Plan**:
  * **Phase 1: Days R+0 to R+7 (Stabilization & Balance)**: Focuses on orthostatic tolerance, recumbent cycling (45° back angle), and inner-ear otolith calibration (VOR x1 gaze fixation drills).
  * **Phase 2: Days R+8 to R+21 (Strength & Hydrotherapy)**: Aquatic buoyancy de-loading (chest-deep water), banded Romanian deadlifts (RDL), and kinetic chain rowing.
  * **Phase 3: Days R+22 to R+45 (Full Earth Readiness)**: Progressive overground track tempo running, dynamic agility ladders, and return-to-pre-flight baseline validation.
* **Daily 2-Hour Physio Block & Gamified Checklist**: Structured breakdown of the daily 2-hour rehab block with timers, animated execution cues, and completion rewards.
* **Active Safety Stop System**:
  * Real-time sliders for **Vestibular Dizziness (0-10)** and **Pain (0-10)**.
  * **Safety Stop Trigger**: If dizziness $> 4/10$ or pain $> 5/10$, the app triggers a pulsing **RED SAFETY STOP**, emits an audible alert, and automatically orders the astronaut to transition to seated/recumbent recovery.
* **Earth Readiness Meter (HealthData.gov NHIS Standards)**:
  * Evaluates overall recovery trajectory toward **100% Pre-Flight Earth Baseline** using standard civilian benchmarks (VO2 Max, unipedal balance duration, orthostatic systolic stability, and bone turnover markers).

## 🚀 Quick Start Guide

### Option A: Run via Python Local Server (Recommended)
```bash
cd astral-med
python server.py
```
Open your browser to: **http://localhost:8080**

### Option B: Run via Node Test Suite
```bash
cd astral-med
npm test
```
Validates the offline JSON rule engine across all 14 clinical and mathematical test vectors.

### Option C: Direct Browser Opening
Simply double-click `astral-med/index.html` in file explorer &mdash; the entire engine is architected with modern zero-dependency ES modules and browser-native APIs!
